TurboWarp custom extension

Text that grows with your stage.

SVG Text keeps say, think, ask, and text-actor content at a consistent visual proportion when you enlarge the TurboWarp stage. Give colors, type, size, alignment, and a bubble direction a style name; then reuse it for bubbles and SVG text skins. Write \n for a deliberate line break.

Quick start

Load once, then keep using Looks blocks.

Standard say, think, and ask blocks automatically use the named default style. Define more styles once after the green flag, then select them in say, think, or setText. The latter replaces the current sprite's skin with styled SVG text.

  1. Load the extension

    Choose Add Extension → Custom Extension and paste this URL: 

    https://cdn.jsdelivr.net/npm/@kubohiroya/turbowarp-svg-text@0.3.0/dist/svg-text.js

  2. Allow VM access

    Enable Run extension without sandbox. Bubble styling needs the TurboWarp VM and renderer.

  3. Define styles at startup

    Run define text style [narration] … after the green flag. A definition contains background, text color, font, relative size, left, center, or right alignment, and a sixteen-way bubble direction.

  4. Show a bubble or text actor

    Use say [text] with style [narration] or set this sprite text [text] with style [narration]. Redefine default to change normal Looks bubbles too.

The documentation button is built in. After the extension loads, the first item in its block palette opens this guide through TurboWarp's docsURI feature.

Responsive sizing

One name controls bubbles and text actors.

A named style stores the background color, text color, font, relative font size, alignment, and one of sixteen bubble placement directions. The original eight values remain available, with intermediate values such as up-up-right and up-up-left. Size 100 uses TurboWarp's normal 14-pixel bubble font on a 480×360 stage; the complete bubble and every SVG text actor remain proportional as the stage grows. Direction applies only to bubbles.

Compass aliases cover all sixteen positions: north, north-northeast, northeast, east-northeast, east, east-southeast, southeast, south-southeast, south, south-southwest, southwest, west-southwest, west, west-northwest, northwest, and north-northwest. Direction input ignores surrounding spaces and letter case.

Direction is measured from the actor center to the bubble body center. Changing the message length or bubble dimensions does not change the requested angle, unless the bubble must be clamped at a stage edge.

You can also enter any number from 0 through 360 using Scratch sprite direction semantics: 0 points up, 90 right, 180 down, 270 left, and 360 up again. Intermediate values such as 30.5 are placed continuously without rounding to a menu direction. Out-of-range values use the initial up-right direction.

stageScale = min(stageWidth / 480, stageHeight / 360) fontSize = 14 × stageScale × styleSize / 100

Maximum width, minimum width, padding, border, corner radius, and tail size follow only the stage scale. The style size changes the font and line height. Style names are case-sensitive after trimming surrounding spaces; a blank or unknown name uses default.

Placement uses the sprite's bounds to find its center and clearance. It follows sprite movement and stage resizing, and is clamped to keep the bubble inside the stage. The initial default direction is up-right.

Intentional line breaks

Write \n where the next line should begin.

Literal escape sequences are converted before display. \n, \r\n, and \r all become real line breaks. Existing real line breaks are left unchanged.

Styled say block

say [Line one\nLine two] with style [narration]

Displays a speech bubble and remembers the selected style if the stage is resized.

Styled think block

think [First thought\nSecond thought] with style [aside]

Uses the standard thought-bubble shape with the named appearance.

SVG text actor

set this sprite text [Title\nSubtitle] with style [title]

Replaces the current sprite skin with escaped SVG text containing one tspan per line.

Behavior reference

What changes—and what stays standard.

Area Behavior
Standard say / think / ask Uses the redefinable default style.
Style definition Reusing a name replaces it and immediately restyles visible bubbles and SVG text actors using that name. Define styles again after project load.
Size and missing names Size is limited to 1–1000. Blank, non-finite, or missing style values fall back safely; an unknown name uses default.
Stage resize Visible bubbles and SVG text actors are regenerated at the new scale.
SVG text actor setText creates an SVG skin for the current sprite. Replacing it destroys the previous extension-owned skin. Animation is not part of this release.
Sixteen-way direction The bubble stays on the selected side of a moving sprite and remains inside the stage. If drawable positioning is not available, TurboWarp's standard placement is retained.
Message lifecycle Stopping, replacement, target tracking, number formatting, and the 330-character limit remain handled by Scratch Looks.
Unsupported renderer Without TextBubbleSkin.setStyle(), styling falls back to the standard bubble. Without compatible private drawing hooks, center and right bubble alignment fall back to left alignment. setText reports an error if SVG skin APIs are unavailable.
Compatibility note. Responsive styling uses feature-detected TurboWarp VM and scratch-render APIs. Keep the extension updated when adopting a new TurboWarp runtime. A runtime without those APIs will continue to display standard bubbles. SVG text actors require TurboWarp's SVG skin APIs.
