TurboWarp custom extension

Bubbles that grow with your stage.

Scalable Bubbles keeps say, think, and ask text at a consistent visual proportion when you enlarge the TurboWarp stage. Use size 100 for the normal proportion, choose another percentage when a line needs emphasis, and write \n for a deliberate line break.

Quick start

Load once, then keep using Looks blocks.

The extension listens to TurboWarp's existing bubble events. Standard say, think, and ask blocks automatically use relative size 100; only scripts that need another size use the two new blocks.

  1. Load the extension

    Choose Add Extension → Custom Extension and paste this URL: 

    https://cdn.jsdelivr.net/gh/kubohiroya/turbowarp-scale-bubbles@main/dist/scale-bubbles.js

  2. Allow VM access

    Enable Run extension without sandbox. Bubble styling needs the TurboWarp VM and renderer.

  3. Choose standard or custom

    Keep normal Looks blocks for size 100, or use say [text] with font size [150].

The documentation button is built in. After the extension loads, the first item in its block palette opens this guide through TurboWarp's docsURI feature.

Responsive sizing

Size 100 means “the normal stage proportion.”

The baseline is TurboWarp's normal 14-pixel bubble font on a 480×360 stage. Width and height are compared separately, and the smaller ratio becomes the uniform stage scale so that a non-standard aspect ratio does not stretch the bubble.

stageScale = min(stageWidth / 480, stageHeight / 360) fontSize = 14 × stageScale × SIZE / 100
14px

480×360, size 100

The original TurboWarp proportion.

28px

960×720, size 100

Twice the stage dimensions, twice the font.

42px

960×720, size 150

The responsive font receives another 150% emphasis.

Maximum width, minimum width, padding, border, corner radius, and tail size follow only the stage scale. SIZE changes the font and line height, so larger type can wrap naturally without turning the entire bubble into an oversized panel.

Intentional line breaks

Write \n where the next line should begin.

Literal escape sequences are converted before display. \n, \r\n, and \r all become real line breaks. Existing real line breaks are left unchanged.

Dedicated say block

say [Line one\nLine two] with font size [100]

Displays a speech bubble and remembers size 100 if the stage is resized.

Dedicated think block

think [First thought\nSecond thought] with font size [125]

Uses the standard thought-bubble type with responsive 125% text.

Behavior reference

What changes—and what stays standard.

Area Behavior
Standard say / think / ask Automatically restyled at size 100.
Custom size Numbers are limited to 1–1000. Blank and non-finite values become 100.
Stage resize The visible bubble is restyled, repositioned, and redrawn.
Message lifecycle Stopping, replacement, target tracking, number formatting, and the 330-character limit remain handled by Scratch Looks.
Unsupported renderer If TextBubbleSkin.setStyle() is unavailable, styling safely falls back to the standard bubble.
Compatibility note. Responsive styling uses feature-detected TurboWarp VM and scratch-render APIs. Keep the extension updated when adopting a new TurboWarp runtime. A runtime without those APIs will continue to display standard bubbles rather than fail a project.
