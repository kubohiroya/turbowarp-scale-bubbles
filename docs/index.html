TurboWarp custom extension

Bubbles that grow with your stage.

Scalable Bubbles keeps say, think, and ask text at a consistent visual proportion when you enlarge the TurboWarp stage. Give colors, type, size, and alignment a style name; then reuse that name in say and think blocks. Write \n for a deliberate line break.

Load the extension Understand size 100

Quick start

Load once, then keep using Looks blocks.

The extension listens to TurboWarp's existing bubble events. Standard say, think, and ask blocks automatically use the named default style. Define more styles once after the green flag, then select them by name in the extension's say and think blocks.

  1. Load the extension

    Choose Add Extension → Custom Extension and paste this URL: 

    https://cdn.jsdelivr.net/gh/kubohiroya/turbowarp-scale-bubbles@main/dist/scale-bubbles.js

  2. Allow VM access

    Enable Run extension without sandbox. Bubble styling needs the TurboWarp VM and renderer.

  3. Define styles at startup

    Run define bubble style [narration] … after the green flag. A definition contains background, text color, font, relative size, and left, center, or right alignment.

  4. Say or think with a style

    Use say [text] with style [narration]. Redefine default to change normal Looks bubbles too.

The documentation button is built in. After the extension loads, the first item in its block palette opens this guide through TurboWarp's docsURI feature.

Responsive sizing

One name controls the whole bubble.

A named style stores the background color, text color, font, relative font size, and alignment. Size 100 uses TurboWarp's normal 14-pixel bubble font on a 480×360 stage; the complete bubble remains proportional as the stage grows.

stageScale = min(stageWidth / 480, stageHeight / 360) fontSize = 14 × stageScale × styleSize / 100
14px

480×360, size 100

The original TurboWarp proportion.

28px

960×720, size 100

Twice the stage dimensions, twice the font.

42px

960×720, size 150

The responsive font receives another 150% emphasis.

Maximum width, minimum width, padding, border, corner radius, and tail size follow only the stage scale. The style size changes the font and line height. Style names are case-sensitive after trimming surrounding spaces; a blank or unknown name uses default.

Intentional line breaks

Write \n where the next line should begin.

Literal escape sequences are converted before display. \n, \r\n, and \r all become real line breaks. Existing real line breaks are left unchanged.

Styled say block

say [Line one\nLine two] with style [narration]

Displays a speech bubble and remembers the selected style if the stage is resized.

Styled think block

think [First thought\nSecond thought] with style [aside]

Uses the standard thought-bubble shape with the named appearance.

Behavior reference

What changes—and what stays standard.

Area Behavior
Standard say / think / ask Uses the redefinable default style.
Style definition Reusing a name replaces it and immediately restyles a visible bubble using that name. Define styles again after project load.
Size and missing names Size is limited to 1–1000. Blank, non-finite, or missing style values fall back safely; an unknown name uses default.
Stage resize The visible bubble is restyled, repositioned, and redrawn.
Message lifecycle Stopping, replacement, target tracking, number formatting, and the 330-character limit remain handled by Scratch Looks.
Unsupported renderer Without TextBubbleSkin.setStyle(), styling falls back to the standard bubble. Without compatible private drawing hooks, center and right alignment fall back to left alignment.
Compatibility note. Responsive styling uses feature-detected TurboWarp VM and scratch-render APIs. Keep the extension updated when adopting a new TurboWarp runtime. A runtime without those APIs will continue to display standard bubbles rather than fail a project.
