TurboWarpカスタム機能拡張

ステージと一緒に大きくなるテキスト。

SVG Textは、TurboWarpのステージを拡大しても、say・think・askとテキストアクターを ステージに対して一定の見た目で表示します。色・フォント・サイズ・文字揃えにスタイル名を 付け、吹き出しとSVGテキストスキンで共有できます。意図した位置に\nを書くと改行できます。

機能拡張を読み込む サイズ100の意味を見る

使い始める

一度読み込めば、通常の「見た目」ブロックも対応。

通常のsay・think・askは defaultという名前のスタイルを自動的に使います。緑の旗の直後に必要なスタイルを 一度定義し、say／thinkまたはsetTextから名前で選びます。 setTextは現在のスプライト自身をSVGテキストスキンにします。

  1. 機能拡張を読み込む

    拡張機能を追加 → カスタム拡張機能を選び、次のURLを貼り付けます。 

    https://cdn.jsdelivr.net/npm/@kubohiroya/turbowarp-svg-text@0.1.0/dist/svg-text.js

  2. VMへのアクセスを許可

    サンドボックスなしで実行を有効にします。吹き出しの調整にはTurboWarp VMとrendererが必要です。

  3. 開始時にスタイルを定義

    緑の旗の後でdefine text style [narration] …を実行します。 背景色・文字色・フォント・相対サイズ・左／中央／右揃え・8方向の表示位置を 1つの名前に保存します。

  4. 吹き出しまたはテキストアクターを表示

    say [文字] with style [narration]または set this sprite text [文字] with style [narration]を使います。 defaultを再定義すると通常の「見た目」ブロックも変更できます。

ドキュメントボタンが組み込まれます。 機能拡張を読み込むと、ブロックパレットの先頭にTurboWarpのdocsURIによる ガイドボタンが表示され、この英語ガイドを開けます。右上から日本語へ切り替えられます。

画面サイズへの追従

1つの名前で、吹き出しとテキストを指定。

名前付きスタイルには背景色・文字色・フォント・相対フォントサイズ・文字揃え・表示方向を 保存します。吹き出しの方向は上・右上・右・右下・下・左下・左・左上の8種類です。サイズ100は 480×360の標準ステージにおけるTurboWarp既定の14ピクセルで、ステージを拡大しても 吹き出しとSVGテキストアクターの比率を維持します。方向は吹き出しだけに適用します。

stageScale = min(stageWidth / 480, stageHeight / 360) fontSize = 14 × stageScale × styleSize / 100
14px

480×360、サイズ100

TurboWarp本来の吹き出し比率です。

28px

960×720、サイズ100

ステージの縦横が2倍なので、文字も2倍です。

42px

960×720、サイズ150

画面追従後の文字をさらに150%へ強調します。

吹き出しの最大幅・最小幅・余白・枠線・角丸・しっぽはステージ倍率だけに追従します。 スタイルのサイズは文字と行高に追加適用されます。スタイル名は前後の空白を除いて 大文字・小文字を区別し、空欄または未定義の名前はdefaultになります。

方向はスプライトのboundsを基準にし、スプライト移動とstageサイズ変更に追従します。 stage外へ出る場合は表示領域内へ収めます。初期default方向は up-rightです。

意図した位置で改行

次の行を始める位置に\nを書く。

表示前にリテラルのエスケープ表現を改行へ変換します。\n、\r\n、 \rはいずれも実際の改行となり、最初から含まれている改行はそのまま維持されます。

スタイル付きsayブロック

say [1行目\n2行目] with style [narration]

発言の吹き出しを表示し、ステージ変更後も選択したスタイルを維持します。

スタイル付きthinkブロック

think [最初の考え\n次の考え] with style [aside]

標準の思考吹き出し形状を、指定した名前の見た目で表示します。

SVGテキストアクター

set this sprite text [題名\n副題] with style [title]

現在のスプライトスキンを、各行を安全にエスケープしたSVGのtspanへ置換します。

動作一覧

変わるものと、標準のまま維持されるもの。

対象 動作
通常のsay・think・ask 再定義可能なdefaultスタイルを使います。
スタイル定義 同じ名前を再定義すると置き換え、表示中の吹き出しとSVGテキストにも即時反映します。 プロジェクト読込後は定義ブロックを再実行します。
サイズと未定義名 サイズは1〜1000に制限します。空欄・有限でない値・不正なスタイル値は安全な 既定値となり、未定義のスタイル名はdefaultになります。
ステージサイズの変更 表示中の吹き出しとSVGテキストを新しい倍率で再生成します。
SVGテキストアクター setTextは現在のスプライトにSVGスキンを作成します。 置換時は以前に機能拡張が所有していたスキンを破棄します。0.1.0ではアニメーションしません。
8方向の表示位置 移動するスプライトの選択方向に吹き出しを維持し、stage内に収めます。 drawable位置更新に非対応ならTurboWarp標準配置を維持します。
メッセージの寿命 停止、置換、対象追従、数値の整形、330文字制限は標準Scratch Looksへ委譲します。
非対応renderer TextBubbleSkin.setStyle()がなければ標準の吹き出しへ、対応する 内部描画処理がなければ吹き出しの中央／右揃えを左揃えへ安全にフォールバックします。 SVG skin APIがなければsetTextは明示的なエラーを返します。
互換性について。 画面追従には、存在確認を行ったうえでTurboWarp VMとscratch-renderのAPIを使います。 新しいTurboWarp runtimeへ更新するときは、この機能拡張も更新してください。必要なAPIがない runtimeでは標準の吹き出しを表示します。SVGテキストアクターにはTurboWarpのSVG skin APIが必要です。
